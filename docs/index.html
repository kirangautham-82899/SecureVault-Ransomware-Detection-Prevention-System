Honest about what it is

SecureVault doesn't replace a full commercial antivirus suite, which blocks malware before it runs using kernel drivers and cloud intelligence. Windows already includes an excellent free one, Microsoft Defender, so keep it on.

SecureVault adds what Defender doesn't focus on: ransomware-specific monitoring, honeypots, clear explanations and a calm interface. It even uses Defender as a second engine for deep scans.

FAQ

Questions, answered

Is SecureVault really free?

Yes. There are no ads, no account and no subscriptions, and the full source code is public on GitHub.

Windows says "Windows protected your PC". Is that normal?

Yes. SmartScreen shows that for new apps that aren't code-signed with a paid certificate. Verify the checksum (see below), then click More info and Run anyway.

How do I know my download is genuine?

Only download SecureVault from this website or its GitHub Releases page. Each release lists the zip's SHA-256 checksum (also in SHA256SUMS.txt). In PowerShell, run (Get-FileHash .\SecureVault-Windows.zip).Hash and check that it matches. Every release is built automatically from the public source code by GitHub.

How do I install it?

Download the zip, extract it anywhere (for example Documents\SecureVault) and run SecureVault.exe. No installer and no admin rights needed. Your settings, logs and quarantine live in %LOCALAPPDATA%\SecureVault.

Does my data leave my computer?

No. There are no accounts, ads, analytics or telemetry, and everything runs locally. The only exception is the live stream, and only while you have it on: viewers with your private link see its status page, with folder paths and your user name hidden by default. Internet links close automatically after 2 hours, and SecureVault tells you whenever someone opens your stream.

How do I watch from my phone?

Click Go live, then turn on Allow devices on my network (same Wi-Fi) or Share over the internet (anywhere). Internet sharing needs Cloudflare's free tool: winget install Cloudflare.cloudflared.

Found a security problem?

Please report it privately through GitHub's private vulnerability reporting rather than a public issue.
