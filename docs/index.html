FAQ

Questions, answered.

Is SecureVault really free?

Yes. There are no ads, no account and no subscriptions, and the full source code is public on GitHub.

Windows says "Windows protected your PC". Is that normal?

Yes. SmartScreen shows that for apps that aren't code-signed with a paid certificate. Verify the checksum, then click More info → Run anyway.

How do I know my download is genuine?

Only download from this site or GitHub Releases. Each release lists its SHA-256 checksum (also in SHA256SUMS.txt). In PowerShell, run (Get-FileHash .\SecureVault-Windows.zip).Hash and check that it matches.

How do I install it?

Extract the zip anywhere and run SecureVault.exe. No installer or admin rights. Your data lives in %LOCALAPPDATA%\SecureVault.

Does my data leave my computer?

No. Everything runs locally. The only exception is the live stream, and only while it's on: viewers with your private link see its status page, with folder paths and your user name hidden by default. Internet links close after 2 hours.

How do I watch from my phone?

Click Go live, then turn on Allow devices on my network or Share over the internet. Internet sharing needs Cloudflare's free tool: winget install Cloudflare.cloudflared.

Found a security problem?

Please report it privately through GitHub's private vulnerability reporting.
